## 启动数据工作的前置条件
1. 确认数据发布方的正式许可文本和适用版本。
2. 取得覆盖学生创新项目、模型训练、演示、再分发限制及商业化路径的书面授权或法律意见。
3. 建立数据来源、授权日期、允许用途、保存期限和访问人员清单。
4. 明确是否含人脸、视频、音频、位置或驾驶行为等个人信息，并完成适用的隐私影响评估。

## 仓库规则
- 仅提交数据说明、可公开的元数据模式、下载说明模板和预处理代码。
- 不提交原始视频、标注文件、派生人脸图像、模型权重、训练输出或任何真实凭据。
- data/、models/、outputs/ 仅保留 .gitkeep 占位文件。
