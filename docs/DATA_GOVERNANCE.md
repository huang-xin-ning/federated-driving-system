# 数据治理与 DMD 使用记录

## 当前状态

- 候选数据集：DMD Driver Monitoring Dataset。
- 本地状态：已下载 pilot 压缩包和标注元数据；已提取极少量视频用于帧边界验证。
- 当前使用：仅进行元数据检查、样本清单规划和视频帧边界验证。
- 训练状态：未开始。当前 pilot 只有 1 个驾驶员组，低于任务要求的至少 3 组。
- 商业使用与公开展示状态：未确认。不得假定其可用于吉利资助项目的商业化或后续产品。

## 进入正式训练前的条件

1. 确认数据发布方的正式许可文本和适用版本。
2. 取得覆盖学生创新项目、模型训练、团队协作、演示、模型权重或派生结果发布限制及商业化路径的书面确认或法律意见。
3. 建立数据来源、授权日期、允许用途、保存期限和访问人员清单。
4. 明确是否含人脸、视频、音频、位置或驾驶行为等个人信息，并完成适用的隐私影响评估。
5. 获得至少 3 个不同驾驶员组，并通过项目训练前条件检查。
6. 确认台式机硬件、训练框架、依赖版本、随机种子、数据划分与实验记录方式。

## 仓库规则

- 仅提交数据说明、可公开的元数据模式、下载说明模板、预处理代码和测试。
- 不提交原始视频、标注文件、派生人脸图像、模型权重、训练输出或任何真实凭据。
- `data/`、`models/`、`outputs/` 可以存放本地文件，但实际内容必须被 Git 忽略。
