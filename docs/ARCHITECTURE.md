# 系统架构（第一阶段）

## 目标
构建面向智能网联汽车的驾驶员行为监测原型：各车辆或边缘节点保留本地视频与特征，仅交换受控的模型更新；服务端聚合更新后分发全局模型。

## 原型边界
- 第一阶段只处理离线、经授权的数据和可复现实验。
- DMD 数据集尚未下载，也未确认商业使用授权；不得下载、上传或用于训练。
- 不采集真实车内人脸或身份信息，不把原始视频、可识别图像或凭据提交到 Git。

## 逻辑组件
1. 数据节点：本地读取授权数据、切分训练/验证集、生成最小化模型更新。
2. 客户端训练器：在每个节点执行本地训练和评估。
3. 聚合服务：验证参与者更新、聚合参数、记录版本和指标。
4. 推理服务：加载经过批准的模型，仅输出风险类别、置信度和必要的审计事件。
5. 治理与审计：记录数据授权状态、模型版本、训练配置和访问事件。

## 联邦学习流程
1. 服务端发布已批准的全局模型版本。
2. 客户端使用本地授权样本完成有限轮训练。
3. 客户端仅提交受保护的模型更新与聚合统计信息。
4. 服务端执行加权聚合、评估和版本登记。
5. 只有通过质量和隐私检查的模型才可进入推理测试。

## 隐私与安全基线
- 原始数据始终留在数据节点，不进入代码仓库或聚合服务。
- 后续评估安全聚合、更新裁剪、差分隐私及成员推断防护；第一阶段不宣称已实现。
- 密钥、令牌、环境变量文件和本地路径必须被 .gitignore 排除。
- 任何实际部署都应在数据授权、个人信息保护评估和安全评审完成后进行。
