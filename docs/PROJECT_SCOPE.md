# 项目范围记录

## 当前范围

本项目当前定位为学生创新研究原型，用于学习、方案验证和经批准的学术/竞赛展示；当前不开展商业运营、产品销售、真实车辆部署或面向公众的数据采集。

## 数据边界

- DMD Driver Monitoring Dataset 尚未下载。
- 在确认数据发布方许可、署名义务、训练允许范围和展示限制前，不下载、不训练、不再分发数据。
- 不把原始视频、标注、可识别图像、模型权重、日志中的个人信息或访问凭据提交到仓库。

## 商业化转换门槛

若未来转入吉利资助项目的产品化或商业合作阶段，必须重新完成：数据与模型使用授权确认、个人信息与安全评审、真实车内采集的告知/同意机制、部署风险评估以及合作方审批。

## 记录维护

发生范围、数据来源、许可或合作对象变更时，更新本文档并在 Git 提交说明中标明原因。
