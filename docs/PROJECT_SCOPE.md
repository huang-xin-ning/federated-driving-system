# 项目范围记录

## 当前范围

本项目定位为学生创新研究原型，用于学习、方案验证和经批准的学术或竞赛展示。当前不开展商业运营、产品销售、真实车辆部署或面向公众的数据采集。

## 数据边界

- 本机已取得 DMD pilot 数据压缩包与标注元数据，仅用于本地只读检查和流程验证。
- 当前 pilot 只有 1 名驾驶员，不能用于正式按驾驶员分组训练、正式联邦学习实验或对外模型效果结论。
- 在确认数据发布方许可、署名义务、训练允许范围、团队共享范围和展示限制前，不进行正式训练、不公开模型权重或派生数据、不再分发原始数据。
- 不把原始视频、标注、可识别图像、模型权重、日志中的个人信息或访问凭据提交到仓库。

## 商业化转换门槛

若未来转入吉利资助项目的产品化或商业合作阶段，必须重新完成数据与模型使用授权确认、个人信息与安全评审、真实车内采集的告知与同意机制、部署风险评估以及合作方审批。

## 记录维护

发生范围、数据来源、许可或合作对象变更时，更新本文档，并在 Git 提交说明中标明原因。
