# 联邦轮次校验与合成数值原型

## 轮次元数据校验

`federated_driving.rounds.validate_round` 是联邦轮次的第一层安全边界：

- 只接收 `ModelUpdate` 元数据；不读取原始视频、标签或特征。
- 拒绝空轮次、同一轮中重复的客户端，以及不同基础模型版本的更新。
- 返回参与者数量与样本数总量，供未来的聚合器和审计日志使用。

## 合成向量 FedAvg 原型

`federated_driving.fedavg.aggregate_fedavg` 只对测试使用的数值向量执行样本数加权平均：

- 至少需要 2 个客户端更新。
- 每个客户端必须使用相同基础模型版本。
- 所有向量必须非空、长度相同且数值有限。
- 权重来自客户端声明的样本数。
- 它不加载模型、不传输梯度、不读取驾驶数据，也不代表生产级安全聚合。

可运行下列演示：

```bash
.venv/bin/python scripts/demo_fedavg.py
```

该命令只使用脚本内部写死的两个合成向量，并输出加权平均结果和 `Training: NOT STARTED`。

## 合成向量更新裁剪原型

`federated_driving.update_clipping.clip_l2` 会计算 L2 范数，并在超过上限时等比例缩小合成向量：

- 拒绝空向量、非有限数值与非正上限。
- 返回裁剪前范数、裁剪后的向量和是否发生裁剪。
- 它可以作为未来异常更新限制策略的基础，但单独使用不构成差分隐私、安全聚合、加密传输或完整攻击防护。

演示命令：

```bash
.venv/bin/python scripts/demo_update_clipping.py
```

真正的模型参数聚合、加密传输、差分隐私和安全聚合仍需在数据授权、单机基线验证和安全评审通过后单独设计和验证。
